## Summary

Semantic ports of the Wave 1 bug fixes: stale pre-trigger frame reuse, ToupCam all-zero frames,
LAPE int16 overflow, stage timeout math (`min`→`max`), focus-map double move, corrupt
`last_coords.txt` tolerance + atomic writes, XY restore on stages without Z, Celesta/laser-engine
timeouts, Preferences inline-comment parsing, laser-AF `.ini` crop sizes, filter-wheel startup guard,
region shapes, single-FOV snap focus map, 1536-well row ordering, emission filter wheel index (all 4
call sites, upstream fixed 2), live FPS pacing, Continuous trigger-mode gating, X-Light emission
skip, shared-QSpacerItem double free, idempotent close, shared illumination line, FTDI latency
warning, and FastLED/PacketSerial pins.

## Architecture Adaptations / Deviations

- `f453dc18`: restore gate lives in `application.py::_initialize_hardware` (not `main_window.py`).
- `2a550c86`: unknown spot-param guard placed in `backend/processing/laser_spot.detect_spot`
  (`SPOT_DETECTION_PARAM_KEYS`); simulation fallbacks untouched.
- `74824168`: also ported `_ini_text()` so quoted free-text paths survive a save.
- `2092c2ee`: position reset to unknown before each write so a failed write is retried (addition).
- `df83fe32`: shared bijective base-26 row index; also fixes `ZarrWriterInfo.get_hcs_structure` row sort.
- `1f4130f2`: tests use our `on_connection_lost` callback instead of a Qt signal.
- Not ported (deferred): firmware resend plumbing (`72bdd2fc`), PI C-414 FTDI call (`26a80322`),
  VersaLase driver (`85917dc7`), upstream firmware CI guard (`9d8a5f56`), ImageDisplayWindow timer
  half (`53ddb024`, n/a).
- Firmware `platformio.ini` change is config-only and **not built** here — verify on hardware.
